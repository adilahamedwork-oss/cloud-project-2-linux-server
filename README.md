AWS EC2 Linux Web Server Deployment

Project Overview

Deployed a personal website on an AWS EC2 instance running Ubuntu Linux and configured Nginx as the web server.

Technologies Used

* Amazon Web Services (AWS EC2)
* Ubuntu Linux
* Nginx
* HTML and CSS
* Linux command-line administration
* Networking and HTTP

Implementation Steps

1. Launched an Ubuntu EC2 instance.
2. Connected to the instance using EC2 Instance Connect.
3. Installed and configured Nginx.
4. Created a custom HTML website.
5. Configured network access through the EC2 security group.
6. Accessed the website through the instance’s public IPv4 address.

Skills Demonstrated

* Basic cloud server deployment
* Linux file and directory management
* Web server configuration
* Basic networking and HTTP troubleshooting

Project Outcome

Successfully hosted a custom personal website on an AWS EC2 instance using Nginx.

Future Improvements

* Configure a custom domain and HTTPS.
* Add monitoring and logging.
* Automate deployment using a shell script.
